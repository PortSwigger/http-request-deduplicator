UniReq deduplicates HTTP requests passing through the proxy by generating a SHA-256 fingerprint from the request method, host, normalized path, and body content. Only unique requests are tracked and displayed, reducing noise when analyzing large volumes of traffic.

Features

  • Deduplicates requests using a fingerprint of METHOD | HOST | NORMALIZED_PATH | SHA-256(BODY), so requests differing only in headers such as Cookie or User-Agent are treated as duplicates
  • Live request table showing method, host, path, status code, and timestamp for each unique request
  • Filter bar supporting host pattern matching with regex, case-sensitive, and invert toggle options, plus filtering by HTTP method and status code
  • Advanced filters for MIME type, file extension include/exclude lists, per-method and per-status-range filtering, and restriction to in-scope targets only
  • Integrated request and response viewer pane for inspecting the full content of any selected entry
  • One-click export of the currently visible filtered results to JSON, CSV, or Markdown
  • Stores up to 1000 unique entries using FIFO eviction; data is held in memory only for the current session

Usage

  1. Enable the extension by turning on the Enable toggle in the UniReq tab.
  2. Browse your target normally. UniReq automatically captures and fingerprints each request passing through the proxy.
  3. Open the UniReq tab to view the live table of unique requests.
  4. Use the filter bar at the top of the table to narrow results by host pattern, HTTP method, or status code.
  5. Click Advanced Filters to configure additional filters such as MIME type, file extensions, status code ranges, or scope restriction.
  6. Click any row in the table to inspect the full request and response in the viewer pane below.
  7. Click Export to save all currently visible table entries to a JSON, CSV, or Markdown file.
